## Why structured nodes (not full 116 KB HTML)

- Skill guidance: keep focused on attribution and compliance; avoid reproducing entire Apache 2.0 / MIT full texts unless a specific node is requested.
- Full original license texts (including ObjectivePGP Canary-specific commercial note, OpenSSL dual license, Realm binary terms, Firebase notices, etc.) remain available at the live source URL.
- Structured form is ideal for multi-device review (Samsung Android Working Copy / Termux + Apple), Linear issues, and OrgSuite Codex App documentation.
